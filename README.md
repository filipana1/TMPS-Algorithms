# Threshold-Based Prototype Selection for Multi-label Nearest Neighbour Classification
Instance-based multi-label classifiers can be computationally expensive. They retain the training instances and search them during classification. Reducing the training set can therefore improve their efficiency. In this work, we propose Threshold-based Multi-label Prototype Selection (TMPS), a new instance reduction method for multi-label data. TMPS evaluates each training instance based on its consistency with its local neighborhood. Each instance receives a local consistency score. This score is computed from the average Hamming loss between its label vector and those of its nearest neighbors. Instances with a score below a threshold are removed. The threshold is not fixed in advance. Instead, it is selected through validation for each dataset. This allows TMPS to adapt the amount of data reduction to the characteristics of the dataset. The reduced training set is used by a Binary Relevance k-Nearest Neighbors (BRkNN) classifier.
We evaluate TMPS on nine multi-label benchmark datasets. The results show that TMPS can substantially reduce the training set while maintaining competitive predictive performance. We also compare TMPS with random undersampling that retains the same number of instances. TMPS achieves lower Hamming loss on all nine datasets. The results show that local neighborhood consistency can be effectively used to construct compact training sets for instance-based multi-label classification.
